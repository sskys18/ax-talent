This folder contains the real AI conversation log artifacts for submission:

- `ai-conversation-chatgpt-share.txt` - full visible text export of the shared ChatGPT conversation used to create and review the plugin submissions.
- `chatgpt-share-url.txt` - source URL for the shared conversation.
- `LOG_SOURCE.md` - provenance note explaining why the same full conversation appears in each plugin submission.

Do not generate fake logs.
